## 2.0.0

- Fixed: “The Bitwarden CLI (bw) is not installed – download it under Passwords → Providers” – there was no such place, and the message also came up for people who never set up Bitwarden. Now Hostwerk loads the official program when you connect (button “Connect Bitwarden” / “Connect 1Password”), already starts the download when you add such a vault, and says what to do instead of what is missing. / Behoben: „Bitwarden-CLI (bw) ist nicht installiert – unter Passwörter → Anbieter laden“ – diese Stelle gab es nicht, und die Meldung kam auch bei Leuten, die Bitwarden nie eingerichtet hatten. Jetzt lädt Hostwerk das offizielle Programm beim Verbinden (Knopf „Bitwarden verbinden“ / „1Password verbinden“), startet den Download schon beim Anlegen eines solchen Tresors und sagt, was zu tun ist, statt was fehlt.
- Provider programs without maintenance: `bw` only from Bitwarden’s GitHub release (SHA-256 of the release, Windows signature “Bitwarden Inc.”, fallback vault.bitwarden.com), `op` only from cache.agilebits.com (Windows signature “AgileBits”); test run with an own data folder, update with rollback, broken versions are skipped, Smart App Control is recognised and explained. Only set-up providers are checked – without a Bitwarden/1Password vault nothing is downloaded or reported. / Anbieter-Programme ohne Wartung: `bw` nur aus Bitwardens GitHub-Release (SHA-256 des Releases, Windows-Signatur „Bitwarden Inc.“, Rückfall vault.bitwarden.com), `op` nur von cache.agilebits.com (Windows-Signatur „AgileBits“); Probelauf mit eigenem Datenordner, Update mit Rücksprung, kaputte Versionen werden übersprungen, Smart App Control wird erkannt und erklärt. Geprüft werden nur eingerichtete Anbieter – ohne Bitwarden-/1Password-Tresor wird nichts geladen oder gemeldet.
- pass and lastpass-cli: clear messages with the install command; LastPass via CLI only on Linux/macOS (on Windows by CSV import). / pass und lastpass-cli: klare Meldungen mit dem Installationsbefehl; LastPass per CLI nur unter Linux/macOS (unter Windows per CSV-Import).
- New vault format 3: a random vault key (AES-256-GCM) wrapped with Argon2id (64 MiB, 3 passes); header bound as AAD; older vaults are lifted on unlock; atomic writes. / Neues Tresor-Format 3: zufälliger Tresor-Schlüssel (AES-256-GCM), geschützt mit Argon2id (64 MiB, 3 Durchläufe); Kopf als AAD gebunden; ältere Tresore werden beim Entsperren angehoben; atomares Schreiben.
- New design: three columns (navigation with kinds, favourites, folders, tags, trash and tools – list with website icons and strength dot – detail), good empty states with import, keyboard (Ctrl+F, ↑/↓, Ctrl+C, Ctrl+Shift+C), vault switcher, narrow windows show list and detail one after the other. / Neues Design: drei Spalten (Navigation mit Arten, Favoriten, Ordnern, Schlagwörtern, Papierkorb und Werkzeugen – Liste mit Webseiten-Symbolen und Stärke-Punkt – Detail), gute Leerzustände mit Import, Tastatur (Strg+F, ↑/↓, Strg+C, Strg+Umschalt+C), Tresor-Wechsel, schmale Fenster zeigen Liste und Detail nacheinander.
- New: SSH keys (create, paste, hand over to Hostwerk’s SSH keys), passkeys (kept, exported to Bitwarden and KeePassXC), encrypted attachments, 2FA from a QR code (image or clipboard) with a countdown ring, more identity and card fields, generator rules per site (also for the browser extension), adjustable clipboard clearing, website icons cached locally. / Neu: SSH-Schlüssel (erzeugen, einfügen, an Hostwerks SSH-Schlüssel übergeben), Passkeys (bleiben erhalten, Export nach Bitwarden und KeePassXC), verschlüsselte Anhänge, 2FA aus QR-Code (Bild oder Zwischenablage) mit Ablaufring, mehr Felder für Identitäten und Karten, Generator-Regeln je Seite (auch für die Browser-Erweiterung), einstellbares Leeren der Zwischenablage, Webseiten-Symbole lokal zwischengespeichert.
- Import of KeePass .kdbx and XML, 1Password .1pux, Bitwarden JSON with password, Enpass JSON and any CSV with your own column assignment – with preview and duplicate count. Export encrypted (KeePass, Bitwarden with password); unencrypted only after a clear warning. / Import von KeePass .kdbx und XML, 1Password .1pux, Bitwarden-JSON mit Passwort, Enpass-JSON und jeder CSV mit eigener Spaltenzuordnung – mit Vorschau und Duplikat-Zählung. Export verschlüsselt (KeePass, Bitwarden mit Passwort); unverschlüsselt nur nach deutlicher Warnung.
- Daily encrypted backups of Hostwerk vaults in the backup centre (14 kept, restore keeps the current state first). / Tägliche verschlüsselte Sicherung der Hostwerk-Tresore in der Sicherungs-Zentrale (14 Stände, Zurückholen sichert vorher den aktuellen Stand).
- Security report: passkeys count as a second factor; findings can be filtered by kind. / Sicherheitsbericht: Passkeys zählen als zweiter Faktor; Befunde lassen sich nach Art filtern.
- Many more tests: crypto format and migration, attachments, every import/export round trip with self-made sample files, provider programs with fakes (missing, outdated with rollback, blocked, wrong signature/address). / Viel mehr Tests: Krypto-Format und Anheben, Anhänge, jede Import/Export-Rundreise mit selbst erzeugten Beispieldateien, Anbieter-Programme mit Attrappen (fehlt, veraltet mit Rücksprung, blockiert, falsche Signatur/Adresse).

## 1.1.0

- Vault as a service for other extensions (`host.use('passwordVault')`: status, save, find, reveal) – each extension only sees its own entries, every access is logged. / Tresor als Dienst für andere Erweiterungen (`host.use('passwordVault')`: status, save, find, reveal) – jede Erweiterung sieht nur ihre eigenen Einträge, jeder Zugriff wird protokolliert.
- Dashboard tile “Password check” with the score and leaked, weak and reused passwords of the default vault. / Kachel „Passwort-Prüfung“ mit Punktzahl und geleakten, schwachen und mehrfach genutzten Passwörtern des Standard-Tresors.
- Export as an encrypted KeePass file (.kdbx, KDBX 4 with Argon2id) with its own password – folders become groups, 2FA and own fields come along. / Export als verschlüsselte KeePass-Datei (.kdbx, KDBX 4 mit Argon2id) mit eigenem Passwort – Ordner werden Gruppen, 2FA und eigene Felder kommen mit.
- Fixed: 1Password and Dashlane exports were recognised as Apple Passwords (tags and 2FA got lost). / Behoben: 1Password- und Dashlane-Exporte wurden als Apple-Passwörter erkannt (Schlagwörter und 2FA gingen verloren).
- Many more tests: every import format, export → import, transfer, KeePass file, sharing, automatic browser pairing, expired keys and the routes of the browser extension. / Viel mehr Tests: jedes Importformat, Export → Import, Übertragen, KeePass-Datei, Teilen, automatische Browser-Kopplung, abgelaufene Schlüssel und die Routen der Browser-Erweiterung.
- Browser brand colours live in one place with a reason (only in the small browser mark); numbers in the leak check follow Hostwerk’s language. / Browser-Markenfarben an einer Stelle mit Begründung (nur im kleinen Browser-Zeichen); Zahlen in der Leak-Prüfung folgen Hostwerks Sprache.
- The release contains the offline catalogue (`data/`) again – it packs everything except the repository tooling. The page sits at the bottom next to “Live”; other extensions may add tabs. / Das Release enthält wieder den Offline-Katalog (`data/`) – es packt alles außer dem Repo-Werkzeug. Die Seite steht unten bei „Livebetrieb“; andere Erweiterungen dürfen Reiter ergänzen.
